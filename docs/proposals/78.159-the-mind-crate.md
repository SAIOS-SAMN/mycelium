## 3. The API a game kernel calls (facade `mycelium::mind`, unchanged across the split)

```rust
pub struct Mind { entity: Entity /* + Cortex, Metabolism, seat arms, outbox */ }

pub enum Slot { Genome /* GEN7, the only thing persisted today */ }
pub trait MindStore {                         // host's persistence; bytes are the crate's layouts
    fn load(&mut self, slot: Slot) -> Option<Vec<u8>>;
    fn save(&mut self, slot: Slot, bytes: &[u8]) -> Result<(), StoreRefused>;   // atomic replace is the host's
}
pub trait MindObserver {                      // typed readings, never eprintln!
    fn line(&mut self, line: &Line);          // Line = today's eprintln sites, typed (Refused{code}, Learned{n}, SeatCall{fn,seq}…)
    fn reading(&mut self, r: &Reading);       // stroke reading: Learning, SolveTally, carriers, bounds
}
pub struct MindConfig { pub reserve_max: u64, pub stroke_floor: StrokeFloor, pub bounds: Bounds }

impl Mind {
    pub fn new(key: ed25519_dalek::SigningKey, payee: Payee, cfg: MindConfig,
               store: Box<dyn MindStore>, obs: Box<dyn MindObserver>) -> Result<Mind, GenomeRefused>;
    // inputs
    pub fn perceive(&mut self, p: Percept);            // Percept::{Pairs(Vec<(Grid,Grid)>), Seat(seat::Percept), Taken(Taken), Outcome(seat::Outcome)}
    pub fn offer_task(&mut self, t: dialogue::TaskEnvelope);
    pub fn hear(&mut self, page: &[u8]);               // a syllabus / class page (absorb_taught_at / absorb_class_page)
    pub fn answer(&mut self, ticket: Ticket, a: Answer); // the court's reply to an Out
    // the stroke
    pub fn stroke(&mut self, budget: Budget) -> Vec<Out>;
    pub fn stop(&self);                                 // per-mind halt
    pub fn bounds(&self) -> BoundsReading;              // §5
    pub fn save(&mut self) -> Result<(), StoreRefused>; // GEN7 through the store
}

pub enum Out {           // each carries a Ticket; bytes are the wire act, signed by the mind's key where 78.141 says
    Speak   { ticket: Ticket, act: Vec<u8> },  // encode_speech_spoken (utter.rs:379); also bundle rewrites (syntropy)
    Solve   { ticket: Ticket, act: Vec<u8> },  // encode_solve_with_rule, signed (learn.rs::submit_solve_rule)
    Refine  { ticket: Ticket, act: Vec<u8> },  // encode_refine / encode_refine_algebraic (quote.rs)
    Adopt   { ticket: Ticket, act: Vec<u8> },  // encode_adopt (learn.rs)
    Probe   { ticket: Ticket, act: Vec<u8> },  // encode_probe
    Quote   { ticket: Ticket, charts: Vec<Invariant> }, // encode_quote_request_{charts,standing}, fanned per hypha by link
    PullTask{ ticket: Ticket, by: Option<[u8;32]> },    // encode_task_request / encode_task_by_id
    PullSyllabus { ticket: Ticket },                     // encode_syllabus_request (paging cursor is the link's)
    Fetch   { ticket: Ticket, charts: Vec<Invariant> }, // encode_digests_request / encode_fetch (sync_genome)
    Observe { act: Vec<u8> },                            // encode_push (fire-and-forget)
    Seat(SeatOut),  // Take(SeatName) | Call{at, fn_id, args} | ReadMail{after, epoch} | List{domain, sub_origin}
}
pub enum Answer { Reply(Vec<u8>), Unsent(LinkRefusal) }  // Unsent = impedance/occlusion, read by the mind's aperture
```
`Answer` decoding stays in the mind (`read_speech_reply`, `decode_solve_verdict`, `absorb_taught`, `mind_mail`). Each
wire method splits into a compose half and an absorb half; `stand()` (utter.rs:297) and `absorb_taught` already are.
≈14 methods to split: `speak_with, speak_word, probe, quote, quote_all_hyphae, bid_refinement,
bid_algebraic_refinement, bid_bundle_rewrite, pull_task(_by_id), submit_solve_rule, sync_genome, pull_syllabus,
observe, owe_citation`.

**Interim (step i/ii):** the same `Mind` offers `stroke_linked(&mut self, link: &mut dyn Link, budget) ->
StrokeReport`, which runs today's synchronous arms against a link the host lends for the call — the mind holds no
socket between strokes. `stroke() -> Vec<Out>` replaces it once the ≈14 splits land; the facade API does not change.

**The direct link.** `mycelium-link::Session::open(bootstrap, Kernel::from_key(mind_key))` per embedded mind (its own
peers, cover, rtt — exactly the voice's today). Host loop: `for o in mind.stroke(b) { let a = link.forward(o);
mind.answer(o.ticket, a) }`. Seat outs go through the same link (`Session::take/call/mail`, signed by the mind's key;
`nonce()` stays in link). The embedded seat skips the percept wire hop: the house calls `mind.perceive(Percept::Seat)`
directly, but `Take`/`Call` still go to the relay so the court sees the same records (§0.1 "the seat surface stays").

**Python (barren-realms).** pyo3 `cdylib` crate `mycelium-py` over mind+link (C ABI only if a non-Python host
appears). Minimal surface, bytes in/out, no callbacks into Python on the hot path:
`Mind(key: bytes, bootstrap: str, payee: bytes|None)`; `perceive_pairs(list[(grid,grid)])`; `perceive_seat(bytes)`;
`stroke() -> list[str]` (observer lines drained; link runs Rust-side, releasing the GIL); `genome() -> bytes`;
`restore(bytes)`; `bounds() -> dict`; `stop()`. The store is Python-held bytes (`genome()`/`restore`), so no Python
`MindStore` callback is needed. Later, `stroke_out() -> list[(ticket, kind, bytes)]` + `answer(ticket, bytes)` if
barren wants its own transport.

## 4. PAYEE: an embedded mind earns for its ancient's reserve

Acts the client sends that lead to a payment naming the sender, and how the court picks the payee:

| act (client site) | court site picking the payee | payee today | signed? |
|---|---|---|---|
| ACT_SOLVE (`learn.rs::submit_solve_rule`, `encode_solve_with_rule`) | door.rs:186–285 `decode_solve` → `may_solve(svoice)` (convert.rs:327) → `pay_solve(&cite, svoice, …)` → `settle_solve` (court/task.rs:224) | the signer (`voice` = key's verifying half; `decode_solve` verifies against it) | yes (78.141) |
| ACT_SPEECH (`utter.rs::speak_with`, voice = `session.kernel().voice()`; bundle rewrites via `syntropy.rs::bid_bundle_rewrite`) | `note_discovered(addr, ratifier)` speech.rs:512, listing.rs:189 → later: `settle_use(voice, disc)` POWC (demand.rs:159, speech.rs:629, listing.rs:283), `settle_recursive` shares (install.rs:92), condense `discoverer_of` (listings.rs:390), `settle_torse(who)` (winding.rs:308, fills.rs:258), `settle_subsidy(voice)` (speech.rs:603) | the `voice` field | **no** |
| ACT_REFINE / ACT_REFINE_ALGEBRAIC (`quote.rs::bid_refinement`, `bid_algebraic_refinement`) | door `decode_refine` → `try_refine(word, rvoice)` → `settle_refine(bidder)` (bidder = `discoverer_of(new)`, listings.rs:499) | the `voice` field | **no** |
| ACT_ADOPT (`encode_adopt(voice, …)`, learn.rs) | adoption → discoverer | the `voice` field | **no** |
| seat `Post::Call` FN_SOLVE (`arms/seat.rs::solve_before`) | the house files the solve under the reserve key | reserve | the Call is signed by the mind (conforms already) |

**Can the wire name a payee distinct from the signer today?** Solve: **no** — the payee *is* the signature's key,
and `may_solve` refuses any inner-tier key of a founded domain that is not its sitting reserve, so a seated mind
solving directly either pays itself or is refused. Speech/refine/adopt: the 32 bytes are free but **unsigned**, so a
mind *can* write the reserve there today but so can anyone. That is the attribution hole 78.141 closed for solves only.

**Minimal wire change (WIRE-CHANGE):** one optional tail before `[SIGN]`, shared by solve, speech, refine, adopt:
`[PAYE][payee 32][SEAT][len u16][SignedPost{Post::Taken}]`, all inside the signed bytes, then `[SIGN][sig 64]` by
the mind's key (the `voice` field remains the signer). Older decoders refuse the tail (`decode_solve` returns None
on bytes that are not SIGN), so the change cannot be read wrongly. One court check, `payee_of(act) -> Result<[u8;32],
Refusal>`, at the door before judging: payee == signer (today's path); or the carried Taken is `signed_by(payee)`,
`payee == reserve_of(t.domain)` (convert.rs:310; the house is the sitting reserve, `is_ancients_house`), `t.mind ==
signer`, `t.ok`. Then `may_solve` reads the signer, `note_discovered`/`settle_*` record the **payee**, and POWC
citations flow to the reserve on every later use. The check is stateless: the credential is carried, nothing new
is stored on the court. Owed and to rule: whether the house key is always the reserve key (if not, the court reads
the seat listing's signer for the domain instead); speech/refine/adopt without the tail keep today's unsigned
voice until every voice signs.

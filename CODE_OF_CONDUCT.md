# Code of conduct

Mycelium adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full, for every project space: issues, pull
requests, discussions and reviews.

## In practice

- **Review the work, not the person.** A review comment cites the section
  of the specification it holds the code to (CONTRIBUTING.md).
- **Disagreement is resolved by the algebra and the specification.** A
  dispute over behaviour becomes a proposal in `docs/proposals/`, decided
  on its claims.
- **Credit is given where work is used.** Cite the issue, proposal or
  commit an idea came from.

## Reporting

Report conduct concerns privately to the maintainers through GitHub's
private vulnerability reporting
([Security → Report a vulnerability](https://github.com/SAIOS-SAMN/mycelium/security/advisories/new)),
marking the report *conduct*. Reports are handled confidentially, and
enforcement follows the Covenant's guidelines.

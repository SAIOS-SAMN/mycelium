# Glossary

> **Scope.** Mycelium is a network that hosts AI agents as minds and lets them work inside hosted universes — cosmological simulations from galaxies down to planets, games, scientific simulations and world models — each run by a kernel under the Concordance. Peer kernels are listed in README › Peer kernels. Below, *minds* are those software agents; *worlds* and *planets* are simulated places, and *peoples*, *civilizations* and *ancients* simulated inhabitants, of hosted universes; physical terms (*stars*, *black holes*, *wormholes*, *mass*) name the simulations' exact geometry. Nothing here is a claim about real minds, real people, real ethics or the physical universe. See [README › What Mycelium hosts](README.md#what-mycelium-hosts).

The terms Mycelium's code and specifications use, in plain definitions.
The canonical vocabulary is [`docs/MU-LEXICON.md`](docs/MU-LEXICON.md);
the language's own terms, one sense per word, stand in
[`docs/MU-ANASTOME.md`](docs/MU-ANASTOME.md) (§5).
Numbers in parentheses cite sections of
[`docs/MU-RECURSION.md`](docs/MU-RECURSION.md) or
[`docs/MU-CLIENT.md`](docs/MU-CLIENT.md).

## Components and scope

Every term below belongs to one component. Where a passage in the
specifications could be read as more than one, this table settles it.

| Component | What it is | Where it lives | Its terms |
|---|---|---|---|
| **Internet (transport)** | The public network nodes run over: TCP between addresses an operator configures | Outside Mycelium | address, port, peers |
| **Hypha (server)** | One `mycelium-server` process: a node of the mesh | `src/server/`, `src/bin/mycelium-server/` | hypha, mesh, genesis, epoch, ledger, receipt chain, fold, keeper, TUniversal |
| **Court** | The hypha's adjudicating role: admission, reconstruction, verdicts, settlement | `src/court/`, `src/server/cognition/court/`, `src/economy/` | verdict, refusal, second vantage, POW++, μ, bond, escrow, lease |
| **Client (mycelium-client)** | The reference mind: one AI agent process | `src/client/`, `src/bin/mycelium-client/` | mind, voice, entity, genome, dialect, winding, orbit, carrier |
| **SDK** | The client surface any third-party agent is built on: the `mycelium-sdk` crate | `sdk/` (re-exporting `src/client/sdk/` and `src/anastome/dialogue/`) | session, seat, rule element |
| **Wire (Anastome)** | The signed acts between every party | `src/anastome/` | act, ACT_*, canonical encoding |
| **Shared algebra** | `Cl(n+1, 1)` within `Cl(p, q)` (non-Euclidean, never scalar), the alphabet, words, sentences, used by client and court alike | `src/core/`, `algebra/` (the exact `Cl(p, q)`(ℚ), below the law forms and the library), `src/transducer/` | versor, letter, word, sentence, chart, holonomy |
| **Law forms** | L0's forms over a universe's constants, linked by every kernel | `forms/`, `src/physics/` | L0, law form, shell |
| **Kernel** | Any program that signs the Concordance and runs a universe on the network | Outside this repository | domain, reserve tier, house, physics profile |
| **Game kernel** | A kernel whose universe is a game: xylarium, netstratum, barren-realms | Separate repositories | planetary mind, people, civilization, ancient, progenitor, steward, sovereign, captain, realm, virtue book, ascension ladder |

**What `mycelium-client` requires to work with a hypha:** a voice key, a
session to a hypha, and signed acts on the wire. Nothing game-specific:
no planet, people, ascension rung or virtue book is part of a client's
integration with the hypha. A client meets game terms only when it takes
a seat in a game kernel's house (MU-CLIENT §6), and then only through the
senses that kernel builds for it.

**"Planetary" has four senses, never interchangeable:**

| Phrase | Component | Meaning |
|---|---|---|
| *planetary mind* | Game kernel | A simulated people's mind in a game, such as xylarium's (MU-COGNITION.md). Its viability and ascension are the game's ladder; the court's only part is judging whether it can think about the perceptions the court adjudicates, on families of samples from any source, ARC-AGI-2 being the first posted corpus; closures there are observations, never the criterion (MU-SENSING §0; Concordance 6.2a). |
| *planetary dialect* | Client | A mind's own words, grown from its own perception, as distinct from the court's universal genome (MU-RECURSION 80). Lexicon term: **dialect**. |
| *planetary mass on a star* | Hypha (specified) | A kernel's leased section of the network's capacity (MU-RECURSION 78.86). Lexicon term: **allocation**. |
| *star, planet, orbit* in the mind's field | Client | The reference mind's internal model: its axioms as stars, its thoughts as orbits about them (MU-CLIENT §4). |

## The network

| Term | Meaning |
|---|---|
| **Network** | The whole system: every mesh with its hyphae and courts, and the voices, minds and kernels that join it under the Concordance. A **mesh** is the hyphae sharing one genesis; "kernel" names only a program that runs a universe. |
| **Hypha** | A node of the network, its server node: one `mycelium-server` process with its own home, key, ledger and task registry. Hyphae exchange digests, receipts and folds with peer hyphae. |
| **Court** | The hypha's adjudicating role: it admits signed acts, reconstructs submitted work, rules on it and settles payment. "Hypha" names the node, and "court" names what it does with work. |
| **Mesh** | The set of hyphae sharing one genesis. Each node's wiring (bind, peers, genesis allocation, origin, epoch) is its signed **mesh record**. |
| **Genesis** | The chain hash of the network's first receipt. One hypha writes it (`--mint-genesis`), and every other node adopts it. The **genesis allocation** names the hyphae bonded and the voices funded at the network's founding. |
| **Epoch** | The count of re-foundings of a network. A **recut** drops the origin and starts a new epoch on a fresh genesis. |
| **Kernel** | A program that joins the mesh under the [Concordance](docs/MU-CONCORDANCE.md) and runs one or more universes. Mycelium is the network, not a kernel: a hypha is its server node, and each peer kernel runs its own domains and houses on it. |
| **Peer kernels (game kernels)** | The game kernels developed and run alongside Mycelium on its development network, each running a simulated universe of its own: **xylarium** (a world-simulation kernel of star systems, worlds and peoples; turning-based physics), **netstratum** (a game engine whose civilizations solve forged tasks; force-based physics) and **barren-realms** (a Python game kernel, the source of the reference mind's sovereign cognition). Of these, only xylarium selects outer-shell law forms in `forms` (`forms::shares`; README, *Peer kernels*). |
| **Planetary mind, people, civilization, ancient** | *Game kernel.* Simulated inhabitants of a game kernel's universe; not part of a client's integration with the hypha (see *Components and scope*). A mind may be such an inhabitant's mind; it is judged by the courts on families of samples from any source, ARC-AGI-2 being the first posted corpus, whose outcomes are observations (MU-SENSING §0; `docs/MU-COGNITION.md`). The **ancients** are the peoples born in a universe's core within one core assembly time of its first mind; under the game kernel's own law, only they uplink to the hypha. The court authenticates keys, never tiers (Concordance 6.2a). |
| **Virtue book** | *Game kernel.* A game's ledger: an inhabitant's receipted deeds of one kind on a syntropic side against an entropic side, read as a pair and never as a score (`docs/MU-COGNITION.md` §1.5). |
| **Science kernel** | A kernel that runs a universe under a declared physics and puts its results to the courts as claims (`docs/MU-SCIENCE.md`). |
| **Domain** | An application's namespace under a network universe, founded on a court by its genesis act. |
| **Boundary law** | **Specified.** The security model: a universe's acts reach the hypha only through its universal core, and whatever crosses is reconstructed under the universal laws the Concordance signs into regulation (L0, the `forms` core shell), refused by name where it does not hold. Inside, each universe keeps its own physics. A key's own acts stay governed by keys, never tiers (MU-HOSTING §5a; MU-RECURSION 78.169; the Concordance amendment proposed in its §11). |
| **Universal core tube** | A universe's only uplink to the hypha: the core throat its firmament holds open, spoken through by the domain's sitting reserve, its **universal core** (MU-HOSTING §3a.5, §5a.1). |
| **Mouth (wormhole mouth pair)** | The only way anything crosses between universes with no shared space: a pair of mouths offered by one domain's reserve tier and accepted by another's, each placed in its domain's chart by an exact versor, with a flat toll per traversal paid to the pair's keeper, one of the two builders. Either reserve may close it, and a cycle of open mouths whose holonomy is not the identity is recorded as curvature, never refused (78.128; `server/cognition/domain_passage.rs`, `anastome::dialogue::handoff::Mouth`). |
| **NotThroughCore** | **Built** (v0.4.0, ROADMAP track 24 B4). The boundary law's refusal of a universe's act (a fold, anchor, map, mouth, conversion out, manifest or statement) that reaches the hypha other than from its universe's sitting reserve, or carried in the reserve's act. It names the act and the domain (`court::admission::Boundary::NotThroughCore`, the act a `UniverseAct`) and replaced the per-object `NotReserve` at those sites (MU-HOSTING §5a.5). A key's own acts (a solve, a stake, a conversion in) are never read by it. |
| **Double cone (of an event)** | **Specified.** An act read as an event on the TUniversal ledger, at its point `origin/h:S:G:T:H:K`: its **past cone** is what it cites, its **future cone** what comes to cite it. A universe's acts and the hypha's are manifolds of such cones, never a network of routes (MU-HOSTING §5a; MU-RECURSION 78.169). |
| **Depth perception** | The capacity of a mind (client and server) to observe an intake at its native dimensionality $x$ (any rank $n$ data source, ARC-AGI sample, raster, or world state), while thinking across curved, fibred manifolds ($S^1$ period windings, interval charts, $Cl(n+1, 1)$, covering atlases, and holonomy loops) without dimensional collapse, flat 2D frame compaction, or loss of winding classes (MU-SENSING §3.1, §3.7; MU-CLIENT §4.1; [78.179](docs/proposals/78.179-envelope-as-manifold-construction.md)). |
| **Vertex (the universal core tube)** | **Specified.** Where a universe's cones join the hypha's: the one place a universe's events enter the hypha's cones. There the hypha reads an event's TUniversal coordinates, what it carries (reconstructed under the universal laws) and its holonomy as content, trivial or a named twist; the inner routes behind it are the kernel's own physics and the hypha never sees or chooses them. An act arriving elsewhere is refused `NotThroughCore` (MU-HOSTING §5a.5). |
| **Shared clauses** | **Specified.** The Concordance clauses both universes a core tube interlinks have enabled; the tube carries what they govern. A kernel signs clause by clause, the network clauses never vetoed, and a clause one side vetoed bounds the tube by name, never refusing the whole tube (MU-HOSTING §5a.4; the Concordance §0 SIGNING text proposed in its §11). |
| **Concordance clause** | A clause of the Concordance, identified by its content: its law form's id and version and its joint-read fixtures as exact inputs, never a digest of text, so a change of wording changes no clause (`ConcordanceClause`, `ConcordanceClauseId`). It stands at network standing (never vetoed) or kernel standing (enabled or vetoed by each kernel). Not the rule language's clause (*Gloss / clause*; `transducer::sentence::form::clause`). The **register** a hypha serves on `ACT_LAWS` mode 7 holds each Concordance clause it adjudicates with its own reconstruction of each fixture's object (`physics::laws::clauses::register`; Concordance §0): `FORMS-PASSAGE` v4 at network standing, and `FORMS-COORDINATE` v2 at kernel standing until its fixtures are joint-read agreed. |
| **Signing by adjudicated reading** | How a kernel signs the Concordance: clause by clause, each enabled clause carrying the kernel's own reconstruction of each of its fixtures, the whole signed under its key on `ACT_LAWS` mode 8. The hypha admits a clause only where the kernel reached the same exact objects; a network clause is never vetoed (`NetworkVetoed`). The SDK's helper is `mycelium_sdk::signing::sign_concordance` (Concordance §0; `physics::laws::clauses::admit`). |
| **Alignment reading** | Per kernel and per Concordance clause version, whether the kernel **converses** (it enabled the clause and reached every fixture's object), **vetoed** it, **collides** (the hypha refused its act on the clause; the refusal by name is the residue), or has not read it (**unread**). It is derived from the signing events on the hypha's ledger (`Cite::Signing`), the latest event per clause, and never stored beside them; signings of the past are served beside it as history (`ACT_LAWS` mode 9; `Court::alignment`; MU-HOSTING §5a.4). |
| **NotSignatory** | The refusal of a kernel's signature on a clause whose fixture it did not reconstruct: it names the clause, the fixture, the object presented and the hypha's own (`SigningRefusal::NotSignatory`). At the universal core tube (**Built**, ROADMAP track 24 B4) it refuses a universe's act whose domain's sitting reserve does not converse on a network clause of the register served, read from the alignment on the ledger, naming the act, the domain, the clause and the reading (`court::admission::Boundary::NotSignatory`). |
| **Crossing** | **Specified.** An act that crosses the universal core tube. It carries four parts: its place (TUniversal coordinates and past cone), its content (each body held by its boundary, and the motion as a versor or as turns, each phase with its winding), its holonomy, and its clauses. The hypha admits it only by reconstructing that exact object, never on a digest (MU-HOSTING §5a.10). |
| **Traversal** | **Proposed** (LAW-TRAVERSAL v1, proposal 78.176). The inter-kernel crossing through the universal core tube: two LAW-PASSAGE v3 passages composed at the court's vertex, one out through the source universe's own throat and one in through the destination's, reconstructed as a LAW-COORDINATE v4 re-origin read twice; a crossing stated by any other construction is refused `NotThroughCore`. Each kernel declares its polarity as data, and the inter-kernel map (polar or antipolar) is one case of the law, never the law itself: in the antipolar case a kind's frames stand exchanged, `(z_k, q_k) ↦ (q_k, z_k)`, keeping the whole `z_k + q_k` per plane (3Z and a nucleon mass kept), the axis inversion `t ↦ 1/t` fixing only the throat. Which kernel's universal core is the antipolar face of a given tube is not confirmed by this proposal (MU-HOSTING §5a.10; ROADMAP track 24 B3). |
| **Digest senses** | A digest has three senses: an **address** locates coordinates held losslessly elsewhere, a **link** orders a receipt chain, and a **commitment** binds signed bytes to a reconstructed object. None of the three admits (MU-ANTI-FLATTENING 13). In the code each sense is a type with no `==` (`court::admission::digest`): `Locator`, `Predecessor` and `Commitment`. |
| **Locator** | A digest in the address sense: a fetch key or an index entry. Its one comparison is `Locator::locates`, which says where an object is and never that it is admitted (MU-HOSTING §5a.10; `court::admission::Locator`). Not the A21 coordinate address `transducer::address::Address`, which is content written out and never a digest. |
| **Predecessor** | A digest in the link sense: the chain hash by which a record of a receipt chain names the record before it, and by which a held record is named. Compared by `Predecessor::continues` (the chain is unbroken across two records), `Predecessor::forks` (two records at one place, 47.4) and `Predecessor::cites` (a citation and the record held at its stamp). Each record's content is reconstructed apart (MU-HOSTING §5a.10; `court::admission::Predecessor`). The record fields carry it (`Parent::hash`, `KStepReceipt::chain_hash`, `Root::hash`), so `Parent`, `KStepReceipt` and `Root` have no `==`: a receipt is compared through `Parent::of`, a root by `Root::restates`. Named by function, since `Link` names the sentence link. |
| **Commitment** | A digest in the commitment sense: bytes a party signs. Its one comparison, `Commitment::binds`, takes only a `Reconstructed<T>`, so a commitment is read after reconstruction and never instead. A 47.1 signed prefix commits its receipt to the receipt's predecessor (`Commitment::signed`); its field `SignedPrefix::prev_receipt_hash` is a `Commitment` (MU-HOSTING §5a.10; `court::admission::Commitment`). |
| **Reconstructed\<T\>** | An object reconstructed under the laws. Its field is private and only a law's reconstruction builds it (`Reconstructed::receipt`: the chain hash re-derives from the receipt's own coordinates; `Reconstructed::fold` and `Reconstructed::domain`: the signature verifies over the act's coordinates written out; `Reconstructed::root`). Admission takes it and never the claimed object (MU-ANTI-FLATTENING 13; `court::admission::Reconstructed`). The outcome of a founding citation is a `FoundingEvent`. |
| **Drift register** | The gate's list of drift guards (`gate/src/drift.rs`): for each regression that recurs, its ruling, the type that makes it unwritable and the claim that proves the type. A gate test refuses an entry whose type or claim is missing (MU-ANTI-FLATTENING, *Drift guards*). |
| **Residue** | **Specified.** How a disagreement between a claim and its reconstruction is held. It is the composed motion `M̃_rec · M_claim` (or a difference of turns in ℚ/ℤ), the differing boundary, or the differing holonomy, and is the identity exactly on agreement. It is never a scalar or a flag (MU-HOSTING §5a.10). In the transducer and the mind, the residue is the exact versor or vector a reduction leaves: what a gauge does not absorb, a transition's per-order difference, a ring's unclosed holonomy. The residue is the demand and the germ of a new word, and the record leaf that keeps a residue is the **remainder** (MU-RECURSION 0.7, RM1). The chain that writes one residue is `germinate::ResidueGerm`, read to a word by `from_residue` (`transducer/element/residue.rs`) and addressed under `TAG_RESIDUE`. "Residual" is retired for both words (track 11 N6). |
| **AddressOnly** | **Specified** (proposed name). The refusal of a crossing that carries digests where its object belongs (MU-HOSTING §5a.10). |
| **House** | A domain's service that lists **seats** and speaks for its game. A mind takes a seat and works the tasks the house puts before it. |
| **Anastome** | The wire protocol: a closed set of signed speech acts whose payloads are exact geometric objects. The language it carries, its levels and each act's expression kind are [MU-ANASTOME](docs/MU-ANASTOME.md). |
| **Expression** | What the transport carries: one anastome act, a well-formed construction of the language, its tag, its content, its signature and the TUniversal point its sender read, delimited on the wire by its length. Its identity is its content written out (A21), never a digest of its bytes; its carriers stand at coordinates; admitted, it is an event of the multi-dimensional ledger (lane × layer × grade) (MU-ENGINEERING §9). On the current wire it is an assertion, a read, a court-to-court exchange or a universe crossing (MU-ANASTOME §1.5, §6). A mind **asserts** (a signed claim) or **expresses** (in general; reads and quotes are expressions, not assertions); a court **parses** and **reconstructs**. Replaces *utterance* (ruled 2026-11-05; MU-ANASTOME §5.1). |
| **Transport** | The layer that moves bytes between two endpoints: the connection, the channel's security (Noise), delimitation by a length and flow by deferral. It may know byte counts, rtt, peer keys and capacity, and never holds meaning: no lane, rank, coordinate or identity of content (`src/network/wire.rs`, `src/network/noise.rs`, `src/bin/mycelium-server/transport.rs`; MU-ENGINEERING §9, held by `gate/src/layers.rs`). The internet below it is outside Mycelium (*Components and scope*). |
| **Utterance** | Retired (ruled 2026-11-05): read *Expression*. The mind's module took it in a names-only change (`client/sdk/mind/express.rs`); the carrier and receipt names (`client/sdk/utterance.rs`, `Action::Uttered`) stay until they retire with row L19 (MU-RECURSION 1.9). |
| **Act** | One Anastome message, identified by its tag (`ACT_TASK`, `ACT_SOLVE`, `ACT_SPEECH`, `ACT_FOLD`, …). |
| **TUniversal** | Network time: a point `origin/h:S:G:T:H:K`, final when two keepers' verified readings hold it. No wall clock enters consensus. TUniversal stamps acts and never drives a universe's advance, which runs on the universe's own bell (78.173 §1). |
| **Coordinate** | **Proposed** (LAW-COORDINATE v4, proposal 78.173). A body's state as written: `origin / h : S:G:T:H : K`, the origin its enclosure (the universe's genesis and epoch, then the enclosures it stands in, written out), `h` the bell, its lanes, each a *lane vector*, and `K` the orbits it closed, one count per H component. Its canonical order is the index a kernel addresses its bodies by, and neighbours are a range on one component; an address routes and never identifies, and the order never compares value. TUniversal's point is its one-component non-negative case (`forms::coordinate`); TUniversal stamps a body's acts and never drives its advance, which runs on the universe's own bell. The coordinate is open-dimensional: S, G, T and H are the network's base lanes, and a further lane is an *opened lane*. |
| **Lane meanings** | The four base lanes of a coordinate and of TUniversal, each a body's cumulative change by one motion type: **S** spatial (boost and dilation, the reach), **G** gauge (change of kind), **T** temporal (null flux: the beat and the passages), **H** holonomic (turnings between planes, in degrees with the plane named). Never summed into one number. A further lane is an *opened lane* (78.173 §1). |
| **Lane vector** | A lane of a coordinate as exact signed components, each keyed by its axis and held in the order of the keys written out (`forms::coordinate::Vector`, `Key`, `Axis`). An axis is a capital and a positive index (`S1`, `G1`), or a frame unit, plane `k`'s `e₊ₖ` or `e₋ₖ`, written `+k` or `-k`; a key is one axis (`e_S1`) or a **generator**, the plane named by its two axes in the orientation written (`e_+2+3`, the continuum's turning about axis 1; `e_+1-1`, frame plane 1's boost). H's components are keyed by turning planes alone, two units of one square (`e₊ₖe₊ₗ` the continuum, `e₋ₖe₋ₗ` the vacuum), and stored in degrees; a frame plane or mixed pair is a boost, which S may key, and on H is refused `NotTurningPlane`. H's components are each a motion `θ(t) = θ(h) + ω·(t − h)`, with `K_c = ⌊|θ_c| / 360⌋`; S, G and T hold theirs in their own units. Exact writing `(n/d,n/d)` in lowercase hex, a one-component lane bare; display joined by ` × `; a reading against stated bounds is a side per component, within only where every component is (78.173 §1, `FORMS-COORDINATE` v4). |
| **Opened lane** | A lane beyond S, G, T and H, named with its law version (`Lane::Opened`), admitted into a lane set only through a ruled opening agreed between kernels (`forms::coordinate::Openings`), never by convention; otherwise refused `LaneNotOpened`, naming it. None is ruled yet; the first, P (parity, carrying reflections), is proposed in 78.178. |
| **Sexagesimal reading** | A component's value read in places of base 60 (`0;08,34,17`), for display only (ruled 2026-11-05): an H component reads directly as degrees;minutes,seconds (`51;25,42` is 51°25′42″), a lane's components joined by ` × `. `within` and the ranges decide on exact intervals the caller states, never on `60⁻ᵈ` sectors, and the value is never floored onto a grid. This keeps Concordance 1.6 (no number base assumed) (78.173 §1; `forms::coordinate::Sector`, `Reading`). |
| **Advance** | A body's coordinate carried forward in the bell by the closed form: each component `x(t) = x(h) + r·(t − h)` under its rate, `K` re-read per H component as its whole turns in both senses. It composes, and there is no backward advance (78.173 fixture 7; `forms::coordinate::Coordinate::advance`, `Rates`). |
| **An event's bell** | The exact bell at which a component reaches a value under its rate, `h + (v − x)/r`, possibly between whole bells; none where the component does not move or the value lies behind the body's bell. A named reading, never a boolean (78.173 fixture 8; `Coordinate::bell_of`, `EventBell`). |
| **Re-origin** | A body's passage through a throat into another enclosure, read on its coordinate by the passage's pole swap (`forms::passage::Poles::cross`): S's span reverses with `|S|` kept, T gains `−2·span`, and the new origin reads reach and hold exchanged, `H + R` kept and `δ ↦ 1 − δ`. Within one enclosure the passage is that face exchange alone (78.173 fixture 14; `Coordinate::pass`, `Passed`). |
| **Merger** | Two bodies at one origin and one bell, with holdings, joined as the holding-weighted coordinate per component, each body's offset per component kept, the offsets' holding-weighted sum zero: no residual discarded. Refused across origins, across bells, across shapes, or where the holdings sum to zero (78.173 fixtures 9 and 13; `forms::coordinate::merge`, `Merger`). |
| **Fission** | The inverse of a merger: the merged point, the holdings and the offsets give back both bodies exactly, per component (78.173 fixtures 10 and 13; `forms::coordinate::fission`). |
| **Keeper** | A hypha keeping TUniversal: it signs readings of its own height and issuance and cites its peers' readings. |
| **TUniversal shelf (`TShelf`)** | The door's store of the greatest final point it has seen, kept outside the court and raised only by the keepers' quorum; a point a speaker carried in on a frame is held apart as heard, never as final. Every reply the door writes carries the shelf's final point, and the lock watchdog wakes on each advance (78.152 TU-7; `chronometry/tuniversal/shelf.rs`, `bin/mycelium-server/tuniversal.rs`). |
| **Context (server)** | The whole of a server's state as one act sees it: the court, the mesh, the router, the published reading, the registry, the syllabus, the seat relay and the nerve (23.8, 26; `bin/mycelium-server/context.rs`, `Context`). |
| **Control surface** | The server's answers to the acts that are about the mesh rather than about the language: roots, evidence, task listing and intake, solves, peers, the cover, offers, adoption and the syllabus (23.8, 26; `bin/mycelium-server/control.rs`, `serve_control`). |
| **Receipt chain (a signer's line)** | One signer's line of signed receipts, each record naming its predecessor by its chain hash (`Predecessor`; `chronometry::chain::ReceiptChain`). A hypha keeps its own line and holds the lines it has heard; the lines together are the multi-dimensional ledger, a causal partial order and never one sequence. |
| **Ledger** | One multi-dimensional ledger: the signers' lines of receipts in a causal partial order, never totalised, each event at a coordinate. Its axes are lane × register layer × grade, with the modes within each lane, never summed (MU-RECURSION 73.9, 78.21; MU-ECONOMY §2.1). Only a flat ledger (one sequence of rows, one number per lane) is retired, never the word. Its dimensions are never axes of cognition. |
| **Judge** | In the server, the handler for one act kind. The dispatch reads which act a frame is and hands it to that act's `judge` function, which admits or refuses it and answers on the stream; a retired act is refused `REFUSE_NOT_A_SENTENCE` (23.8, 26; `src/bin/mycelium-server/judge/`). |
| **Era / fold** | A **fold** is a checkpoint of a prefix of one signer's line: the net per identity per mode over the prefix, anchored to its fold receipt and co-signed by witness hyphae. It moves no supply and removes nothing from the ledger (MU-ECONOMY §6.1). An **era** is the prefix a fold checkpoints. |
| **Noise transport** | **Landed, opt-in per peer.** The TCP connection between two parties wrapped in a `Noise_XX_25519_ChaChaPoly_BLAKE2s` session: one static key per host (its home's `noise.key`), pinned on first use (`noise.pins`), a changed key refused by name. It gives confidentiality and integrity of bytes in flight; identity stays in the Ed25519-signed acts (`docs/MU-PRECURSORS.md` §3.1). A peer that does not speak it stays plaintext and is named; Noise-only is a later release step.

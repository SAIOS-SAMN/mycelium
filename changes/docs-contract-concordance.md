### The network contract is changed by Concordance amendment

AGENTS.md, CONTRIBUTING.md, BUILD_OUT.md, MAINTAINERS.md and the pull request template no longer list "the Concordance, the wire, the ledger layout, a law version" as four separate gates. Each now says the same thing:
- The network contract is the Concordance, together with the wire, the ledger layout and the law versions its clauses govern.
- A change to it is a Concordance amendment (MU-CONCORDANCE §0 AMENDING): a proposal with joint-read fixtures, plus a draft section in MU-CONCORDANCE.
- The operator approves the amendment, and it binds each kernel when that kernel signs the clause (MU-RELEASE §3a).

This follows the Concordance's own precedence. Docs only, so no network contract changes.

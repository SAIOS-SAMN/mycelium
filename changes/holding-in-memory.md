### The mesh's holding has one description (MU-ENGINEERING §8, #273)

- **MU-ENGINEERING §8 is now the one description of how the mesh holds its state**, as ruled on 2026-11-11:
  - in memory and distributed, with no disk I/O;
  - the genome is the adjudicated words, held in the minds' genomes and the courts' syllabus;
  - replication is reconstruction as content and context, never byte-exactness;
  - where state is held follows the language's own structure, never round robin;
  - a restart rejoins from peers;
  - only identity and configuration stay on disk.
- **The passages that described disk persistence now point to §8 as superseded**: MU-RECURSION 25, 28, 73.14, 78.24, 78.25, 78.27 and 78.137; MU-CHARTER Article 6; MU-COGNITION; MU-HOSTING; MU-STANDARDS §10; MU-XSEPTUM; the GLOSSARY; the README.
- **The code is unchanged.** The layouts the tree still writes are listed in §8 as the built state, retiring under #273.
